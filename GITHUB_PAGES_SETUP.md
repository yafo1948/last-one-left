# 5-minute GitHub Pages setup

1. Create a GitHub repository named `last-one-left`.
2. Upload the **contents** of this folder so `index.html` is at the repository root.
3. Commit to `main`.
4. Repository **Settings → Pages**.
5. **Source: Deploy from a branch**.
6. **Branch: main**; folder: **/(root)**; Save.
7. Wait for the green deployment message, then click **Visit site**.
8. Your URL will normally be `https://USERNAME.github.io/last-one-left/`.
9. On iPhone: open that URL in Safari → **Share → Add to Home Screen**.

The AI generator needs the optional server-side Worker described in `README.md`; never put an OpenAI API key into GitHub Pages or client-side JavaScript.
